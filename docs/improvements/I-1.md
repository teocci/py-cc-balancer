# I-1 — Sub-accounts per pair

- **Improvement ID:** I-1
- **Version:** backlog (unscheduled)
- **Status:** 📋 BACKLOG — partially superseded; true isolation still future.
- **Related work:** multi-account credentials delivered via auth profiles (`--profile`); per-account book isolation is [I-8](I-8.md).

## Objective

Give each trading pair true balance isolation so one pair's activity cannot draw on or
distort another's funds, even within a single exchange account.

## Approach

- Multi-account operation already exists at the **login** level via auth profiles
  (`--profile <slug>`, `auth use`), so distinct exchange accounts are already separable.
- Sub-accounts within **one** account remain future work: model an exchange sub-account
  per pair and route balance reads/orders to the pair's sub-account.
- Depends on the venue exposing a sub-account API through ccxt; scope a quirks row per
  supported exchange before promoting to a phase.
