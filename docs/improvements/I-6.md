# I-6 — `--fields` output projection

- **Improvement ID:** I-6
- **Version:** 0.2.0
- **Date:** 2026-07-17
- **Status:** ✅ DONE (432 tests).
- **Related work:** siblings [I-5](I-5.md), [I-7](I-7.md), [I-8](I-8.md).

## Objective

Let an agent request only the fields it needs from a JSON payload, cutting token cost on
large `--json` outputs.

## Approach

- Add a global `--fields a,b,c` flag that projects `--json` payloads down to the named
  top-level keys.
- `--json` output stays compact (no pretty-printing) so the projection is purely a
  key-subset operation.
- Applies uniformly across the JSON-emitting commands rather than being wired per command.

## Files changed

| File | Change |
|---|---|
| `src/ccbalancer/cli.py` | `--fields` added to `_base_flags`; `_emit` projects the payload through new `_project_fields` (top-level key subset) before dumping; text mode ignores it; `--json` stays compact |
| `tests/test_cli_surface.py` | New — `--fields` projection / unknown-key / no-`--json` cases |

## Verification

- `plan --json --fields pairs` → only `{"pairs": …}`; an unknown key → `{}`; `--fields`
  without `--json` is a no-op; `--json` alone is unchanged (compact single-line).
- Covered in `tests/test_cli_surface.py`; full suite (432) green.
