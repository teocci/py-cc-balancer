## Objective

Update DESIGN.md (backtest engine + the network-only-in-stores invariant), add a backtest-limitations / how-to-read-results guide (bar-fill assumption, look-ahead, cycle/overfitting, fees, gaps), and a capped live smoke-test runbook covering the residual risk no backtest removes (auth/real-fill/rejection validation). References deferred fix F-6.

## Approach

- Update `docs/DESIGN.md`: add the backtest engine (data foundation → replay → report), note the
  dedicated replay loop and that all network (ccxt + the Binance fallback) stays in the stores layer.
- New backtest-limitations / how-to-read-results doc: the bar-fill assumption (fills approximated from
  bar range, not proof of liquidity), look-ahead avoidance, cycle/overfitting, fee realism, gap
  handling. Frame the backtest as strategy research, not execution validation.
- New capped **live smoke-test runbook**: one pair at the exchange's smallest min-notional (~$5–10),
  `STOP` kill-switch armed, `max_session_notional_usd` low, `rebalance --execute --confirm <token>`,
  verify the fill in `ledger.jsonl` + on the exchange, then stand down — the residual risk no backtest
  removes (auth / real fill / real rejection). Cross-reference deferred fix F-6.
