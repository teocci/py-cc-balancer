# I-11 — Improve --help (two-layer model, epilog auth, analyze timeframes)

- **Improvement ID:** I-11
- **Version:** 0.3.0
- **Date:** 2026-07-18
- **Status:** ✅ DONE (445 tests; live-verified).
- **Related work:** follows the ADX / Support-Resistance indicator additions

## Objective

Make the tool's purpose and market-intelligence surface discoverable from --help: expand the root description with the two-layer model, add auth to the epilog taxonomy and fix its granularity, and document analyze's valid timeframes + point to indicator list (dynamically, so new indicators stay zero-edit).

## Approach

Surgical edits in `cli.py` (help strings + the hand-maintained epilog), plus one docstring fix:

- Expand the root `description` to 2-3 lines stating the two-layer "CLI computes deterministic
  facts, the agent/human judges & decides to trade" model (`RawDescriptionHelpFormatter` already set).
- `_COMMAND_TAXONOMY` epilog: add the missing `auth` command (login/logout/use/rename = write;
  list/status/whoami = read); split `flag list` / `pair list` / `config show` reads from their
  write siblings.
- `analyze` help: enumerate valid timeframe units (`1m/5m/15m/1h/4h/1d/1w`) and name the default
  set; point to `indicator list` for the computed-indicator catalog — **referenced dynamically**,
  never hardcoding indicator names, so `adx`/`sr` stay zero-edit.
- Nits: `regime` help verb "Flag whether…" → "Report whether…"; `pair add/set` explicit voice.
- Fix stale `indicator_registry.py` docstring: `ccbalancer indicators` → `indicator list`.

## Files changed

| `src/ccbalancer/utils/indicator_registry.py` | Fixed stale docstring `ccbalancer indicators` → `indicator list`. |

- `ccbalancer --help` shows the two-layer model and a complete read/write/audit taxonomy incl. `auth`.

  and references `indicator list` (dynamic — `adx`/`sr` needed no help edit).
- Full suite green (no help assertions regressed).
