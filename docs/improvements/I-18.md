# I-18 — PaperExchangeStore + persistent paper book

- **Improvement ID:** I-18

## Objective

Build the simulated-exchange backend for a paper account: a persistent per-account book plus a
`PaperExchangeStore` that mirrors the full `ExchangeStore` public surface. It reads **real public**
market data through a wrapped real `ExchangeStore` and simulates balances/orders/fills in the book, so
every live command can run against it unchanged. No live-command or manager changes in this phase.

## Approach

- `stores/paper_book.py`: `PaperBook` (balances + orders + id counter) with a `locked()` helper (open
  orders reserve quote for BUYs, base for SELLs) and `PaperBookStore` (atomic `paper_book.json`
  read/write, `seed()` for an all-stable start). No network.
- `stores/paper_exchange.py`: `PaperExchangeStore` composes the book + a real public `ExchangeStore`.
  Market-data methods (`load_markets`/`fetch_ticker`/`fetch_ohlcv[_range]`/`quirks`/`exchange_id`)
  delegate; `fetch_balance` reports total minus `locked` as free; `create_order` rests a maker limit
  after a free-funds check; **`fetch_order` is reconcile-driven** — it fills the resting order at its
  limit once the live ticker crosses it (BUY↓/SELL↑), applying the balance change (with a flat maker
  fee) exactly once so repeated reads are idempotent; `cancel_order` frees the reservation.
- Constants: `PAPER_BOOK_FILENAME`, `DEFAULT_PAPER_CAPITAL`, `DEFAULT_PAPER_QUOTE`, `DEFAULT_PAPER_FEE_RATE`.
- The reconcile-driven `{filled, average, status, fee}` contract means the unchanged
  `ReconciliationManager` books paper fills through the real write-ahead + reconcile path.
