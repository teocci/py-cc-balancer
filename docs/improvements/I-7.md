# I-7 — `profile` → `account` rename

- **Improvement ID:** I-7
- **Version:** 0.2.0
- **Date:** 2026-07-17
- **Status:** ✅ DONE (432 tests).
- **Related work:** siblings [I-5](I-5.md), [I-6](I-6.md), [I-8](I-8.md).

## Objective

Rename the credential entity from "profile" to "account" everywhere so the vocabulary
matches what it actually models — a distinct exchange account/login.

## Approach

- Rename the entity across the stack: `Account` model, its store, config resolution, and
  render/output.
- Env var `CCB_ACCOUNT` becomes primary, with a deprecated `CCB_PROFILE` fallback for
  compatibility.
- Migrate the `auth.json` store key `profiles` → `accounts`.
- The `auth` **command name is unchanged**; add `auth rename` to rename an account.

## Verification

- `CCB_ACCOUNT` selects an account; deprecated `CCB_PROFILE` still resolves; `CCB_ACCOUNT`
  wins when both are set. A pre-0.2.0 `auth.json` (`profiles` key) loads and rewrites as
  `accounts` (live-verified read-only against the real store). Full suite (432) green.
