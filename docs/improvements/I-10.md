# I-10 — Support/Resistance swing-pivot detector

- **Improvement ID:** I-10
- **Version:** 0.3.0
- **Date:** 2026-07-18
- **Status:** ✅ DONE (445 tests; live-verified).
- **Related work:** sibling ADX indicator; extends the Phase 8 indicator engine

## Objective

Provide a deterministic support/resistance level detector (fractal swing pivots, clustered within a tolerance, split by last close) so the agent can retrieve supports[]/resistances[] per timeframe through analyze.

## Approach

Deterministic swing-pivot detector, added as a registry indicator (retrieved via `analyze`; no
new subcommand):

- Pure `support_resistance(highs, lows, closes, *, lookback, cluster_pct, max_levels)` in
  `utils/indicators.py` returning `(supports, resistances)`. Fractal pivots (a pivot high = local
  max with `lookback` lower highs each side; pivot low symmetric), cluster pivots within
  `cluster_pct` into single levels, split by last close (below = support, above = resistance), sort
  by proximity, cap at `max_levels`.
- `DEFAULT_SR_PIVOT_LOOKBACK`, `DEFAULT_SR_CLUSTER_PCT`, `DEFAULT_SR_MAX_LEVELS` in `constants.py`.
- `IndicatorSpec('sr', …)` with the three params.
- `IndicatorSnapshot` gains `supports` / `resistances` (tuples — keep the frozen dataclass
  hashable); `indicators_manager._build()` populates them; `render.py` lists them in `analyze`.
