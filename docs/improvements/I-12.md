# I-12 — Historical OHLCV data foundation — fetch_ohlcv_range + resumable simulation store + `simulation fetch`

- **Improvement ID:** I-12
- **Version:** 0.4.0
- **Date:** 2026-07-18
- **Status:** ✅ DONE (506 tests; live-verified).
- **Related work:** P-18, P-19, P-20

## Objective

Acquire and persist historical OHLCV under ~/.ccbalancer/simulation/ (append-only, resumable — pull only the missing tail since the last closed candle), via a new ccxt fetch_ohlcv_range for 1h/4h/1d, plus a loader that ingests the committed data/simulation sample; expose `simulation fetch`. Normalize everything to ccxt [t,o,h,l,c,v]; manifest tracks provenance/coverage/gaps.

## Approach

- Add `ExchangeStore.fetch_ohlcv_range(symbol, timeframe, since_ms, until_ms)` — loop ccxt
  `fetch_ohlcv(since=cursor, limit=1000)` advancing the cursor by the last open + one interval,
  dropping the still-forming last candle. Keeps network in the store (DESIGN.md invariant); works for
  bybit/binance/okx. (The existing `fetch_ohlcv` hardcodes `since=None` — that's the gap.)
- New simulation OHLCV store: `~/.ccbalancer/simulation/ohlcv/{exchange}/{symbol}/{timeframe}.jsonl`
  + `manifest.json`. **Append-only / resumable** — read the last *closed* candle and pull only
  `since = last_open + interval` forward, appending; never re-download the range; dedup the boundary
  by open-time; stack within a single source only. Distinct from the overwrite-on-write `MarketCache`.
- Normalize all inputs to ccxt `[t,o,h,l,c,v]`; a small loader ingests the committed
  `data/simulation/` CSV/JSONL sample so backtests run with no network pull.
- New constants in `constants.py` (`SIMULATION_DIRNAME`, `SIM_OHLCV_DIRNAME`, `SIM_MANIFEST_FILENAME`,
  …); resolve paths through the existing base-dir config helper (rule 14).
- `simulation fetch` command (new `simulation` group): `--pair`, `--timeframe`, `--start`, `--end`.
- Tests: multi-page pagination + normalization + forming-candle drop; sample-ingest; **resumable
  fetch appends only the missing tail** (no re-download, no boundary dup, prior rows byte-identical).
