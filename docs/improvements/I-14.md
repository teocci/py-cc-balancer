# I-14 — Backtest performance report via PerformanceManager (P&L / ROI + per-year breakdown)

- **Improvement ID:** I-14
- **Version:** 0.4.0
- **Date:** 2026-07-18
- **Status:** ✅ DONE (506 tests; live-verified).
- **Related work:** P-18

## Objective

Mark the sim ledger to market at the final candle's close and emit realized/unrealized/total P&L, ROI, fees, and the per-trade timeline via the existing PerformanceManager, plus a per-year (or per-regime) breakdown to blunt the cycle/overfitting false-confidence trap.

## Approach

- Feed the run's sim ledger (list of `Fill` dicts) straight into the existing
  `PerformanceManager.walk_fills` / `snapshots` / `portfolio_totals` — no reporting logic rebuilt.
- Mark to market using the final candle's close as the "current price" in place of a live ticker.
- Emit realized / unrealized / total P&L, ROI, fees, and the per-trade timeline (JSON + text),
  honoring `--json`/`--fields`.
- Add a per-year (or per-regime) breakdown so a single headline ROI can't hide cycle dependence
  (2017→now is BTC-bull-dominated).
- Tests: a hand-checked toy sim ledger yields the expected realized/unrealized/ROI; per-year
  aggregation sums back to the total.

## Files changed

See the P-19 detail (`docs/phases/phase-19.md`) for the full table. Headline additions:
`managers/simulation_report_manager.py` (`build_report` + `SimulationReportManager`, reusing
`PerformanceManager.walk_fills`), the `simulation report <run_id>` command, and render
`simulation_report_*`. P-18's `run.json` gained `final_base`/`final_stable`/`final_close` for offline
marking.

## Verification

- 506 tests pass. Toy-ledger P&L is hand-checked (realized/unrealized/ROI); the per-year breakdown
  sums back to the totals.
- Live report on the real 2022→2026 daily run: total P&L 16498.76 (ROI 164.99%) ties out exactly to
  `final_value − capital`; per-year realized sums to the total and exposes cycle dependence.
