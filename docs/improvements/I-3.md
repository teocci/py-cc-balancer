# I-3 — Market-order mode

- **Improvement ID:** I-3
- **Version:** backlog (unscheduled)
- **Status:** 📋 BACKLOG

## Objective

Offer market orders as an alternative to the default limit-order rebalancing, for cases
where immediate fills matter more than price control.

## Approach

- Add a market-order execution path alongside the existing limit-order flow in
  `managers/execution_manager.py`, selectable per rebalance run.
- Preserve the current safety guardrails (session notional cap, `STOP` kill-switch,
  confirm-token) for the market path.
- Account for the loss of price control in the decision/what-if output so the agent sees
  the trade-off before committing.
