# I-9 — ADX indicator (Wilder ADX + +DI/-DI + threshold)

- **Improvement ID:** I-9
- **Version:** 0.3.0
- **Date:** 2026-07-18
- **Status:** ✅ DONE (445 tests; live-verified).
- **Related work:** sibling Support/Resistance indicator; extends the Phase 8 indicator engine

## Objective

Give the agent a deterministic trend-strength read per timeframe: Wilder ADX plus directional indicators (+DI/-DI) and a trend-strength threshold, surfaced through analyze and the indicator registry.

## Approach

Extend the existing registry pattern (no new architecture):

- Pure `adx(highs, lows, closes, period)` in `utils/indicators.py` returning
  `(adx, plus_di, minus_di)` series aligned to input with leading `None`. Wilder-smoothed +DM/-DM
  and TR (reusing `_true_ranges`), DX → Wilder-smoothed ADX.
- `DEFAULT_ADX_PERIOD = 14` and `DEFAULT_ADX_THRESHOLD = 25.0` in `constants.py`.
- `IndicatorSpec('adx', …)` in `indicator_registry.py` (`period`, `threshold` params).
- `IndicatorSnapshot` gains `adx`, `plus_di`, `minus_di`, and a deterministic `adx_trend` label
  (trending/ranging vs. threshold — mirrors `rsi_zone`).
- `indicators_manager._build()` computes and populates the fields; `render.py` emits them in
  `analyze` JSON + text.
